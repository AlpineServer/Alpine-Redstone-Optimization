# XiHu's Alpine Redstone Optimization
- ⚡ **A lightweight and practical modpack**.
- 🔧 Built for **hardcore players and creators**, integrating a full suite of tools such as **Carpet**, **Tweakeroo**, **Litematica**, **MiniHUD**, **making complex builds and debugging clear and efficient**.
- 🚀 Meanwhile, it maintains **extremely low performance overhead**, eliminating lag so you can focus on creation.

## 📦 Main Mod List

### 🔌 Redstone Related

- **Carpet** – Adds precise game rules for detailed control and mechanism debugging.
- **Carpet TIS Addition** – Provides advanced technical features and optimizations for Carpet.
- **Litematica** – A client-side schematic projection tool to assist with building.
- **Tweakeroo** – A collection of client-side hotkeys and automation tools.
- **MiniHUD** – Displays customizable information overlays on the screen.
- **Item Scroller** – Enables fast inventory management via mouse gestures.

### ⚡ Performance Optimization

- **Sodium** – Dramatically improves frame rates through rendering optimizations.
- **Lithium** – Optimizes general game logic and performance.
- **Iris** – Enables shader compatibility for the Sodium renderer.

### 🎨 Better User Interface

- **BetterF3** – Replaces and enhances the debug screen for improved readability.
- **Jade** – Displays detailed information about the targeted block or entity.
- **Apple Skin** – Shows detailed hunger and saturation values.

> 📦 **Note**: This modpack also includes many other mods and dependency libraries.

## ✅ Why Choose This Modpack?

- 🚀 **Frequent Updates** – We update the modpack version regularly, allowing you to use the latest mod versions in a timely and stable manner.
- 📉 **Fewer Optimizations** – Some game effects are preserved; for example, you can hold the left mouse button and press F3 + T to keep the key state.
